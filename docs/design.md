# links_map UI 体验优化设计

依据：docs/product.md，需求提交 eb9f774；对应 #product-dev:9e4b461c，task #2。设计交付是本说明，工程负责实现与截图，QA 独立验证。保留现有黑色地球、旅行封面、衬线地点标题、绿色已去与琥珀色想去；不引入新品牌或依赖。

## 1. 布局与视觉

默认视线顺序：地球 → 找地点/随机探索 → 单行统计。选中后：地点图像 → 地名 → 视频 → 个人记录。悬浮容器统一一层表面，去掉「外卡片内再包胶囊再包标签」的重复边框和强光晕。

建议复用值：背景 #030811；面板使用近不透明深色（约 rgba(8,15,24,.94)），1px 白色 12% 描边；桌面圆角 20px，手机抽屉上沿 24px；内部间距 16–20px，相关项目间距 8px，段落间距 20–24px。主要文字 #F5F5F5，正文 #D1D5DB，次要文字 #9CA3AF，勿用低透明白字叠在可变地图/照片上。普通文字目标对比 4.5:1，焦点和必要图标 3:1，工程以实际合成背景核验。

正文与输入 14–16px（手机输入 16px），次要说明 12–13px，按钮 14px，地点标题 28–32px。中文正常字距；不延续大范围 uppercase/tracking。控件主要点击区至少 44×44px；内部图标可为 18px。白色实心主按钮仅用于当前重点（如观看视频/随机探索），状态用图标+文字+选中底色表达，不仅靠颜色。

## 2. 桌面与中间尺寸

断点：宽度 >=1024px 用左右布局；<1024px 用下节单抽屉模式（含平板竖屏），避免 768px 上左右卡片挤满地图。尺寸是实现约束，允许工程在保持验收效果下细调。

1440×900 默认：外边距 20px；左侧导航宽 288px，高度到距离底部 20px；右上只显示 44px 高摘要；地图保持中央最大可见区域；底部工具从导航右缘+16px 开始，在剩余地图区域居中，不伸到列表下方。左侧列表包含品牌「清 · 人生清单」、收起按钮、标题「地点」、搜索、当前结果数、国家分组列表；不再独立叠加左上品牌，也不重复显示三张统计卡。

选中后：右侧详情宽 400px（极限不超过 420px），上下距 20px，内容内部滚动。收起统计展开内容并隐藏摘要，避免压在详情上；底部工具移入左/右面板之间的剩余区域，空间不足时收敛为「筛选」与「随机探索」两个按钮。>=1024px 且剩余地图宽度不足 400px 时，工具同样用紧凑形态，不能为一排完整地区标签挤压面板。

列表开关独立于 selectedId：任何时候都能收起；关闭详情不改变用户之前的列表开关。收起后左上保留品牌和「地点 N」44px 入口；打开不清除查询与折叠状态。桌面详情为非模态侧栏：可继续切换列表、地图和底图，使用有名称的 region/aside，不标 aria-modal=true，不困住焦点。

## 3. 手机/窄屏：同一时刻一个主抽屉

地图全屏铺底，使用 100dvh 与安全区间距；初始无抽屉。顶部左侧为紧凑品牌，右侧为统计摘要。底部距 safe-area 12px 的一行操作：「地点 N」「筛选」「✦ 随机探索」，高度至少 48px。底图切换与地图署名保留且不被底栏永久覆盖。

抽屉宽度 100%，底部贴 safe-area，最大高度约 85dvh。保持顶部一小段地图可见；面板采用 flex/min-height:0，正文区域纵向滚动，顶部栏始终可见。抽屉打开时隐藏背景统计和底栏并禁用背景交互；不同时显示列表、筛选和详情三层卡片。不要求手势拖拽，明确按钮完成全部路径。抽屉使用带标题的模态 dialog，背景 inert，焦点限制在当前抽屉内。

| 当前界面 | 动作 | 结果与恢复规则 |
| --- | --- | --- |
| 地图 | 点「地点 N」 | 列表抽屉；标题/关闭、搜索、结果数、分组列表 |
| 列表 | 点地点 | 原位置替换为详情抽屉，头栏为「返回地点列表」和「关闭详情」；保存搜索、分组与滚动位置 |
| 地图 | 点标记或随机探索 | 直接开详情，头栏「关闭详情」；无虚假的返回列表入口 |
| 来自列表的详情 | 返回 / Escape | 回列表，恢复查询、国家展开状态与滚动，并焦点回到所选行；若该行因状态变化被筛走则回列表标题 |
| 任意详情 | 点关闭 | 直接回地图，保留列表上下文；焦点回原触发入口，失效则回「地点 N」 |
| 地图 | 点筛选 | 筛选抽屉；地区和状态分组、重置与「查看 N 个地点」；选择即时生效，查看/关闭回地图 |
| 列表 | 点列表头「筛选」 | 替换为筛选抽屉，完成/返回恢复列表；不弹第二层 |
| 地图 | 点统计摘要 | 简短统计抽屉，关闭回地图；无抽屉嵌套 |

Escape 在列表/筛选根层关闭并回触发点；不得同时触发多次导航。抽屉关闭按钮始终可见。软键盘出现时输入滚动到可见区，正文可滚动到底，禁止锁死在固定 vh 高度内；保存手记不能只依赖键盘上方不可见的按钮。跨断点保留当前地点、查询和记录；切到窄屏有选中地点时只展示详情。

## 4. 找地点与筛选

保留现有语义：状态与地区同时作用于地图标记、地点列表及随机探索；搜索只在列表按地点名/国家名匹配，不改变地图或随机池。搜索标签「搜索列表中的地点或国家」，有内容时显示「清除搜索」。列表计数写「列表结果 X / 当前筛选 Y」，避免把局部结果叫作全地图可见。全局「地点 N」N 为当前地区/状态筛选后的数量，不随搜索变化。

国家分组头显示国家+数量+折叠箭头，aria-expanded；地点行高至少 56px，缩略图 40px，名称 14px，国家/状态 12px。选中行用左侧竖线+浅底，状态用「✓ 已去」「♡ 想去」，不只放彩色圆点。分组在搜索期间自动展开。返回时不自动 scrollIntoView 覆盖已保存的滚动位置。

桌面宽裕时地区/状态用单层分组按钮，移除每组重复外壳；随机探索单独突出。紧凑筛选展开为一个面板，选择语义与手机一致；不创建新的筛选维度。

| 状态 | 呈现/恢复 |
| --- | --- |
| 搜索无结果 | 「没有找到匹配的地点」+「试试国家名，或清除搜索」+清除按钮 |
| 当前筛选为空 | 「当前条件下暂无地点」+「重置地区与状态」；不清除个人记录 |
| 无可随机地点/只剩当前地点 | 随机按钮禁用，有说明「当前没有其他可探索地点」；不静默点击无响应 |
| 列表图片失败 | 固定尺寸的地点首字/图标占位，不影响行点击与文字 |

## 5. 详情层级与行为

固定头栏提供关闭/返回；正文顺序如下。内容不因封面失败而消失。

1. **16:9 旅行封面**：展示当前视频图像；右下角「1 / N」，多视频才显示上一条/下一条，按钮命名「上一个视频」「下一个视频」。缩略图条紧随封面，避免放在手记之后。去掉「画面：封面」等来源标签。
2. **地点名称**：h2，国家 · 地区一行。移除右侧重复状态胶囊。
3. **关联视频**：当前视频标题，允许换行；「在 YouTube 观看 ↗」主操作，「频道 ↗」为次要链接，明确新标签打开。位置可信度收进原生 details「地点来源」，展示现有可信度与来源信息，不生成未经证实的说明。
4. **我的清单**：并列「♡ 想去」「✓ 已去」切换按钮，aria-pressed。沿用单选语义：选已去替换想去，重复点击当前项取消。选中后文字本身即反馈，不再加一组状态卡。全局计数同步更新。
5. **我的手记**：保留原有折叠与展开能力；有记录默认展开。明确 textarea 标签「旅行手记」、日期标签关联 input。日期可空，未已去仍可写记录；不新增强制日期或校验。保留本地保存语义，失焦与切地点/关闭路径必须可靠提交；成功后显示「已保存到此浏览器」，不要宣称云同步。清空只作用当前地点，并防误触（两步「清空手记」→「确认清空 / 取消」即可）。

切换视频只在非输入元素且有多条时响应左右键；textarea、input、select、contenteditable 内所有编辑方向键保持原行为。0/1 条视频时不做取模导航。切地点必须先保存旧地点草稿，再加载新地点已存内容；不得将旧文本写入新地点。工程需关注 useNote 异步水合与 NoteEditor 初始值的现有实现，防止首次重开得到空文本并覆盖。

| 详情状态 | 用户看到什么 |
| --- | --- |
| 图片探测/加载 | 保留封面固定比例占位和「封面加载中」，地点、视频入口、状态和手记立即可用 |
| 所有图片失败 | 「暂时无法加载封面」，保留原视频标题与外链及其他内容；禁止整个详情 return null |
| 无关联视频 | 「暂无关联视频」，隐藏观看/画廊控制，其余详情照常显示 |
| 手记为空 | 「记录想去的理由或旅行感想」占位，无虚假已保存状态 |
| 保存成功 | 简短状态区礼貌播报，当前地点显示保存时间/已保存；不抢焦点 |
| 本地写入失败 | 「未能保存，请保留文字后重试」；不清草稿、不显示成功，提供重试按钮；状态标记失败也不应假报成功 |

## 6. 统计、地图与可访问性

统计默认只一行「已去 V · 想去 W ▾」，点击才展开总地点数、手记数、待探索、真实进度及「收起」。计数是全部地点的总体统计，不受筛选影响，展开说明「全部地点」。0% 宽度必须为 0；百分比限制 0–100，无人为最小宽度。选中详情时统计收起并隐藏，关闭后回摘要，不自动恢复大卡。

地图保留现有切底图、标记、飞行与署名。加载文案「正在加载地球…」用 status；如果已有可捕获的地图初始化错误，展示「地图暂时不可用」及重新加载入口，列表仍可操作。标记选中状态加轮廓/尺寸区别；无障碍名称至少有地点名。减少闪烁、呼吸和强阴影；prefers-reduced-motion 下除 CSS 动画外，地图自动旋转/飞行动画也停止或即时定位，不重写渲染架构。

所有图标按钮有中文名称，交互保留 2px 清晰 focus-visible 描边及间距。隐藏界面元素不得留在 Tab 顺序（含 H 隐藏模式），提供可聚焦的「恢复界面」按钮；H 不在输入框、抽屉编辑时触发。桌面详情打开后焦点到标题/关闭；非模态侧栏不困住焦点，Escape 仅在详情上下文生效。手机对话框遵守上节焦点规则；背景可见不等于可操作。操作成功、结果计数与保存反馈用礼貌播报，勿每帧播报地图动画。
