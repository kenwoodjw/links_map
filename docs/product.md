## 目标与场景
基于现有产品：用户在地图中发现旅行地点，查看关联视频，标记想去/已去并写手记。本轮提升界面层级、可读性和手机操作完整性，不改变产品定位。目标用户的更精细划分、主要设备比例仍待确认，不据此增加新功能。

## 本轮必须包含
1. 保留深色地球与旅行影像特色，地球为视觉中心；默认统计压缩成简洁摘要，减少重复边框、胶囊和强光晕。品牌与桌面地点导航统一，避免相互叠压。
2. 详情按地点图像、地名/国家、视频与观看入口、想去/已去、手记排序；减少重复状态和低价值标签，提高主要文字和操作可读性。
3. 桌面列表可独立收起；手机明确地图、列表、地点详情的切换关系，避免左右面板同时争抢空间。优先底部抽屉，关闭/返回能回到合理位置与列表状态。
4. 与界面紧密相关的小修：搜索无结果提示与清除入口；0% 进度显示正确；主要交互具备键盘焦点及可访问名称，避免笔记输入方向键触发画廊导航。

## 暂不做
账号、云同步、导入导出、社区分享、AI 推荐、完整行程规划、数据抓取及地理编码流水线改造、地图渲染架构重写、整体更换品牌配色。不得合并、生产部署或使用付费服务；本地预览在授权范围内。如必须修复既有缺陷才能完成主流程，由工程说明最小修复及证据，重大范围变化交 ProductLead 汇总。

## 完整用户流程
打开地图 → 浏览或搜索地点（可清除/恢复）→ 选择地点并查看详情 → 打开视频或标记想去/已去 → 编辑手记 → 关闭详情/返回列表 → 再次打开地点或刷新，记录保持。

## 可验证验收
- 桌面 1440×900 与手机 375×812 下，列表、详情、筛选和主要操作无水平溢出、明显遮挡或不可达；手机软键盘场景应检查或说明验证限制。
- 默认界面地图可见，统计摘要不抢占大块空间；品牌不被列表覆盖。详情文字有清晰主次，主要操作无需在重复标签中寻找。
- 选中地点后仍可收起桌面列表；手机同一时间只有一个主要内容面板，打开/关闭/返回逻辑完整。
- 地点搜索、地区/状态筛选、随机探索和底图切换仍可用；搜索无结果有说明及恢复入口。明确搜索是否仅作用列表，计数文案与作用范围一致。
- 详情仍可看关联视频、标记想去/已去、编辑手记；刷新/重新打开记录保持，不发生串地点或无意覆盖。发现既有问题需明确记录，不能将其隐藏成通过。
- 0% 进度条实际为空；按钮有可读名称、键盘焦点；编辑手记时左右键不切视频；详情焦点行为与实际模态/非模态语义一致。
- lint、类型检查、生产构建均执行，区分本轮问题与基线问题；QA 针对工程明确提交独立检查核心路径并报告证据。环境不支持的检查如实写明。
