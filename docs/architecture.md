# 运行结构与 UI 状态约定

## 运行环境
Next.js 16.2.4 App Router、React 19、Tailwind CSS 4、MapLibre GL 5；首页为客户端交互，GlobeMap 用 next/dynamic、ssr:false 加载。运行时数据来自 data/locations.json，无后端或前端环境变量要求。保留现有底图、地点数据及 localStorage key。

## 界面状态
src/app/page.tsx 统一管理选中地点、飞行目标、地区/状态筛选、桌面列表开关、窄屏当前页面与详情来源。>=1024px 为非模态列表/详情侧栏；<1024px 为 map/list/detail/filters/stats 五种互斥状态。

- 桌面列表开关不依赖选中地点。窄屏列表组件持续挂载但隐藏，保留查询、分组和滚动位置。
- 来自列表的详情允许返回列表；地图或随机探索直接打开详情，不显示返回列表。关闭回地图，尽可能恢复触发点焦点。
- Panel 负责命名、窄屏模态语义与 Tab 边界；背景 inert，隐藏面板使用 hidden，桌面侧栏只在自身上下文响应 Escape。
- 搜索只作用地点列表；地区/状态同时作用地图、列表及随机池。总体统计不受筛选影响。
- 图片失败不阻塞视频链接、状态及手记；地图资源失败给重试入口，地点导航仍可使用。

## 本地记录与失败行为
沿用 links_map:bucket:<id> 与 links_map:note:<id>，分别通过原有自定义 DOM 事件和 storage 事件同步。useLocalRecords 用 useSyncExternalStore 的稳定字符串快照订阅本地记录，服务器快照为空，避免 effect 水合初始空值覆盖已存内容。

手记按地点 ID 挂载，初始值同步读取该地点记录。输入与日期变化立即本地保存，因此关闭、切地点和刷新无需等待失焦。写入成功才播报“已保存到此浏览器”；失败保留当前草稿并提供重试，进程内草稿按地点隔离，重新打开仍可恢复。浏览器刷新无法恢复写入失败的草稿，因此错误提示要求保留文字；不宣称云同步。清空需确认。

未更改抓取、地理编码、账号、同步、地图渲染架构或数据模型。
